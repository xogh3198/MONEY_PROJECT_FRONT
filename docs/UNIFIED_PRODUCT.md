# 홍보지도 × InvestingBoard 통합 제품 기획

마지막 검증일: 2026-07-30

## 한 문장

**홍보지도는 소규모 사업자가 자신의 URL·설명·상품·매장·앱·콘텐츠를 넣으면, 근거가 보이는 홍보 실행지도와 사람이 검수할 수 있는 세로형 영상 초안을 만드는 서비스다. InvestingBoard는 별도 금융 서비스가 아니라 이 구조가 실제로 운영되는 첫 번째 포럼·콘텐츠 사례로 남긴다.**

## 대상과 문제

- 1인 사업자, 소상공인, 초기 스타트업, 독립 제작자
- 홍보는 필요하지만 어떤 채널에서 무엇을 만들지 결정하기 어렵고, 영상 외주비 또는 제작시간이 부담인 사용자
- AI가 알아서 게시하는 도구보다 근거·비용·다음 행동을 확인하고 직접 통제할 수 있는 도구가 필요한 사용자

## 수익 가설

1. 무료 실행지도와 1개 저해상도 영상 초안으로 수요를 검증한다.
2. 검수된 고해상도 렌더, 브랜드 템플릿, 프로젝트 저장을 건별 또는 구독으로 제공한다.
3. 영상 성과가 쌓인 뒤 채널 운영 리포트와 팀 기능을 확장한다.
4. 광고 대행·자동 게시·광고비 집행은 초기 상품에 포함하지 않는다.

수익의 핵심은 영상 개수보다 `사용자가 실제 게시 가치가 있다고 판단한 결과물당 공헌이익`이다.

## 제품 구조

```text
홍보 대상 입력
  URL | 소개글 | 상품 | 매장 | 앱 | 기존 콘텐츠 | 참고 링크 | 사용권 자산
        ↓
근거와 사용자 확인값을 분리한 홍보 브리프
        ↓
채널 우선순위 | 예산 시나리오 | 이번 주 행동 5개
        ↓
30~45초 대본 | 큰 자막 | 7개 장면 | 시각자료 지시
        ↓
사실·표현·자산 권리 사람 검수
        ↓
AI 음성·자막 MP4 미리보기
        ↓
사용자가 직접 게시하고 결과를 기록
```

## 입력 확장 원칙

URL-first이지만 URL-only가 아니다.

| 입력 | 만드는 데 쓰는 근거 | 주의점 |
|---|---|---|
| 웹사이트·링크 | 공식 설명, CTA, 공개 정보 | 본문 자동 수집은 별도 안전 worker와 정책 검토 후 |
| 소개글·아이디어 | 사용자가 확인한 설명 | 입력 밖의 사실 생성 금지 |
| 상품·서비스 | 고객 문제, 사용 장면, 차별점 | 효능·성과·가격의 증빙 필요 |
| 매장·장소 | 지역, 예약, 방문 행동 | 주소·영업시간 최신성 확인 |
| 앱 | 기능, 앱 화면, 설치·가입 행동 | 스토어 정책과 화면 사용권 확인 |
| 기존 콘텐츠 | 원본 작성자의 핵심 주장 | 타인의 기사·영상 단순 재가공 금지 |
| 사진·화면 | 고객 소유 또는 사용 허락 자산 | 권리 메모와 출처 보존 |

## InvestingBoard의 역할

- `/forum`: 금융 뉴스와 커뮤니티 포럼
- 금융 데이터 기반 콘텐츠는 홍보지도 영상 엔진의 내부 테스트 사례가 될 수 있다.
- 과거의 시장·배당·계산기 기능은 당장 삭제하지 않지만 주 내비게이션에서는 제외한다.
- 금융 홍보나 투자성 콘텐츠에는 일반 홍보보다 강한 사실 검수와 정보 제공 고지를 적용한다.

## 기술 구조

- 프론트: 하나의 Next.js/Vercel 프로젝트
  - `/`: 홍보지도
  - `/content-studio`: 비공개 홍보 영상 스튜디오
  - `/forum`: InvestingBoard
- 서버: 기존 EC2 Docker Compose의 `news-service`를 콘텐츠 플랫폼 API로 확장
  - 포트·JVM·환경변수를 추가하지 않고 기존 8083 API 재사용
  - 홍보 대상/계획 API와 기존 비동기 FFmpeg 렌더 API를 같은 서비스에서 운영
- 배포 저장소:
  - 프론트 `xogh3198/MONEY_PROJECT_FRONT`
  - 서버 `xogh3198/MONEY_PROJECT`

GitHub 저장소를 새로 만들거나 다른 저장소에 접근하지 않는다.

## 사용자 진입 구조

두 제품은 같은 운영·콘텐츠 엔진을 사용하지만 고객의 방문 목적은 다르다. 하나의 메뉴에서
동급 서비스처럼 섞지 않고 아래처럼 분리한다.

| 방문자 | 기본 진입 | 기대 행동 | 교차 연결 |
|---|---|---|---|
| 홍보가 필요한 사업자·제작자 | `/` 홍보지도 | 홍보 대상 입력 → 실행지도 생성 | InvestingBoard를 `운영 사례`로 확인 |
| 금융 뉴스·토론 방문자 | `/forum` 또는 개별 기사 | 뉴스 확인 → 관련 기사·커뮤니티 탐색 | `만든 방식`에서 홍보지도 사례 설명 확인 |
| 홍보 영상 파일럿 운영자 | `/content-studio` | 내부 키 → 대본 검수 → MP4 미리보기 | 공개 주 내비게이션에서는 제외 |

- 루트는 두 서비스를 나열하는 포털이 아니라 홍보지도의 전환 랜딩으로 유지한다.
- 금융 방문자가 루트에 잘못 도착했을 때는 `금융 뉴스·토론 보기`로 즉시 분기한다.
- `/cases/investboard`는 두 제품이 함께 있는 이유와 실제 운영 흐름을 설명하는 다리다.
- InvestingBoard 주 내비게이션에서는 `홍보지도` 대신 `만든 방식`을 사용해 이동 이유를 먼저
  전달한다.
- 내부 이동에는 `utm_source`, `utm_medium=internal`, `utm_campaign=product-bridge`를 붙여
  Vercel Hobby Analytics에서도 경로 전환을 비교한다.

## 첫 실험

- 표본: 서로 다른 유형(URL, 상품, 매장, 앱, 콘텐츠) 10건
- 성공:
  - 대본 생성 성공률 95% 이상
  - 운영자가 게시 가치 있음으로 판단한 비율 50% 이상
  - 입력부터 검수 가능한 초안까지 10분 이하
  - 사실·출처·권리 기록 누락 0건
  - 렌더 변동비가 예상 판매가의 30% 이하
- 중단:
  - 사실 오류 10% 초과가 2회 연속
  - 결과물 재생성률 30% 초과
  - 권리 없는 외부 자산에 의존해야만 품질이 나오는 포맷
- 승인 게이트:
  - 외부 계정/OAuth, 유료 API, 결제, 공개 게시, 광고 집행은 사용자 승인 전 실행하지 않는다.
