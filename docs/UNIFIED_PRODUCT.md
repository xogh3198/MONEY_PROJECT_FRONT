# InvestBoard 통합 제품 기획

마지막 검증일: 2026-07-30

## 한 문장

**InvestBoard는 금융 정보를 읽고 토론하는 InvestingBoard와, 서비스의 홍보 계획과 검수형 영상을 만드는 마케팅맵을 하나의 홈페이지 아래 목적별로 연결하는 제품군이다.**

## 대상과 문제

### InvestingBoard

- 20~40대 한국 개인 투자자
- 출퇴근 중 중요한 금융 이슈와 출처를 빠르게 확인하려는 사용자
- 개별 종목 매수 지시보다 맥락, 공개 관심 신호, 다른 사용자의 관점을 원하는 사용자

### 마케팅맵

- 1인 사업자, 소상공인, 초기 스타트업, 독립 제작자
- 홍보할 대상은 있지만 채널·예산·콘텐츠 순서를 정하기 어려운 사용자
- 자동 게시보다 근거와 결과물을 직접 검수하고 통제하려는 사용자

## 수익 가설

1. InvestingBoard의 원본 해설과 도구로 유효 재방문 사용자를 만든다.
2. 마케팅맵의 무료 실행지도와 저해상도 영상 초안으로 제작 수요를 검증한다.
3. 검수된 고해상도 렌더, 브랜드 템플릿, 프로젝트 저장을 건별 또는 구독으로 제공한다.
4. 광고·제휴·구독·영상 렌더 수익은 각각 분리 측정하고 공헌이익이 확인된 모델만 확대한다.

광고는 제품이 아니라 수익화 계층이다. 신뢰와 재방문을 훼손하는 얇은 콘텐츠, 무단 재가공,
자동 광고 상호작용은 사용하지 않는다.

## 제품과 경로

```text
InvestBoard 홈 /
├── InvestingBoard /forum
│   ├── 금융 뉴스·공개 관심 신호
│   └── 커뮤니티 토론
└── 마케팅맵 /promotion-map
    ├── 홍보 대상 분석
    ├── 채널·비용·이번 주 행동
    └── 영상 스튜디오 /promotion-map/studio
        └── 대본·7개 장면 → 사람 검수 → MP4 미리보기
```

- 홈, InvestingBoard, 마케팅맵은 모든 주요 화면에서 같은 순서로 노출한다.
- 홈페이지는 두 제품의 목적과 차이를 설명하고 목적지 선택만 돕는다.
- InvestingBoard 안에서는 뉴스와 커뮤니티가 2차 탭이다.
- 영상 스튜디오는 독립된 세 번째 제품이 아니라 마케팅맵 실행계획의 다음 단계다.
- 과거 `/content-studio`는 `/promotion-map/studio`로, `/cases/investboard`는 `/`로 이동한다.

## 마케팅맵의 제작 흐름

```text
URL | 소개글 | 상품 | 매장 | 앱 | 기존 콘텐츠 | 참고 링크 | 사용권 자산
        ↓
근거와 사용자 확인값을 분리한 홍보 브리프
        ↓
채널 우선순위 | 예산 시나리오 | 이번 주 행동
        ↓
30~45초 대본 | 큰 자막 | 7개 장면 | 시각자료 지시
        ↓
사실·표현·자산 권리 사람 검수
        ↓
AI 음성·자막 MP4 미리보기
        ↓
사용자가 직접 게시하고 결과를 기록
```

URL-first이지만 URL-only가 아니다. 입력 밖의 사실을 생성하지 않고, 고객 제공 자산 또는
사용권이 확인된 자산만 사용한다. 외부 게시, 광고 집행, 유료 공급자 연결, OAuth, 결제는
사용자 승인 전 실행하지 않는다.

## 기술 구조

- 프론트: 하나의 Next.js/Vercel 프로젝트
  - `/`: InvestBoard 통합 홈
  - `/forum`: InvestingBoard
  - `/promotion-map`: 마케팅맵
  - `/promotion-map/studio`: 비공개 홍보 영상 스튜디오
- 서버: 기존 EC2 Docker Compose의 `news-service`를 공통 콘텐츠 플랫폼 API로 사용
  - 기존 8083 API 재사용
  - 홍보 대상·계획 API와 비동기 FFmpeg 렌더 API 운영
- 허용 저장소:
  - 프론트 `xogh3198/MONEY_PROJECT_FRONT`
  - 서버 `xogh3198/MONEY_PROJECT`

## 진입 구조 측정

내부 제품 이동에는 아래 캠페인을 사용한다.

- 세 영역 이동: `utm_campaign=product-navigation`
- 마케팅맵에서 영상 제작 이동: `utm_campaign=marketing-map-video`

Vercel Analytics에서 `/` 이후 `/forum` 또는 `/promotion-map` 이동, 마케팅맵 이후
`/promotion-map/studio` 이동을 확인한다. 표본이 작으므로 유료 분석 도구를 먼저 추가하지 않는다.
